# 6. Types of Setups

Purpose: Show the full range — from the dinkiest DIY desk setup to a professional motion rig — so readers know what exists before choosing. This is the at-a-glance tier map; builds live in [Example Builds](builds/index.md).

> **Prices are preliminary — verify in research phase.** Ranges below are starting points from outline research, not product quotes.

## The Range at a Glance

| Tier | Setup type | Preliminary price range* | Footprint | Best for |
|---|---|---|---|---|
| 0 | Desk clamp / DIY desk setup | ~$280–$1,000 (wheel+pedals on a desk) | Existing desk | Testing the hobby |
| 1 | Wheel stand / foldable cockpit | TODO — cockpit from ~$229 class + wheel/pedals | Folds / stores away | Apartments, shared spaces |
| 2 | First dedicated rig (fixed, single screen) | ~$2,000–$3,000 (complete w/ cockpit class) | ~5 ft × 2.5 ft class | Weekly racing, first load-cell + direct drive |
| 3 | Enthusiast sweet spot | ~$800–$1,200 core controls; complete builds TODO | Fixed rig | Long-term home for most racers |
| 4 | Triples / VR pro-sumer | ~$8,000–$14,000 turnkey triple-screen class | Large fixed rig | Immersion, league/esports focus |
| 5 | Motion / showpiece / pro | ~$16,000–$20,000+ (motion); $60k+ flagship | Dedicated room | No-compromise, training, showpiece |

\* Preliminary ranges to be replaced with sourced, dated figures in the research phase. Assume PC/console may be extra unless stated.
