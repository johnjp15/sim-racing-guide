# Example Builds — Overview

Purpose: Give readers a concrete, copyable build per tier. Each tier has its own page using the same structure, so builds are directly comparable and pages can be added, removed, or reordered easily.

> **Builds are the single source of truth for prices.** The concise [Builds At A Glance](../quick/builds-at-a-glance.md) and [Equipment Finder](../quick/equipment-finder.md) summarise and link here — they do not duplicate price tables.

> **In a hurry?** Start at [Builds At A Glance](../quick/builds-at-a-glance.md) or run the [Equipment Finder](../quick/equipment-finder.md), then open the tier page that fits.

> **All prices preliminary — verify in research phase.** Totals should state whether PC/console and display are included.

## How to read a build page

Every build page uses the same reusable structure:

- **Target user** — who this tier is for
- **Parts table** (TODO placeholders until research verifies products/prices)
- **Estimated total** (preliminary)
- **Footprint**
- **What it feels like** (to write in research phase)
- **Pros / cons**
- **Next upgrade**
- **Used-market alternative**
- **Related links**
