## Cost

### $1,200–$1,600

<small>Assumes: existing PC/console, display, dedicated space</small>

- PC builds now start near $1,060: Moza sells base, wheel and pedals as one bundle

## At a glance

| Spec | This tier |
|---|---|
| Mount | Steel cockpit with a seat, or a budget aluminum profile rig |
| Wheelbase | 8 to 9 Nm direct drive |
| Pedals | Entry load cell |
| Screen | The one you own, on its own stand |
| Space | ~140×70 cm of floor, permanent |
| Build time | 2 to 4 hours |

## Target user

| Good fit | Skip if |
|---|---|
| A permanent spot is available | You can stretch to Tier 3. Its rig and pedals are the buy-once choice |
| Drives weekly | It must pack away (Tier 1) |
| Wants braking that is the same every lap | |

## What it feels like

- Nothing moves when you brake, so muscle memory forms
- 8 to 9 Nm: real weight in fast corners
- Load cell: brake by pressure, not pedal travel
- Slower for the first sessions on a load cell, then more consistent

## Pros / cons

| Pros | Cons |
|---|---|
| Biggest consistency jump per dollar | Tube frames have limited adjustment |
| Always ready to drive | Some wheel deck flex above ~10 Nm |
| Base, wheel, pedals carry to Tier 3 | Proprietary hole patterns and accessories |
| | Permanent floor space |
| | A steel cockpit is replaced at Tier 3. A profile rig is not |

## Next upgrade

- First: better pedals. A mid load cell set
- Then: the rig itself, if on a steel cockpit
- The seat can move across with brackets

## Used-market alternative

| | |
|---|---|
| Look for | Moza R9, Fanatec CSL DD 5 / 8 Nm, load cell pedals |
| Price | New direct drive prices fell in 2026. Used must be clearly under today's new price |
| Check | Fanatec QR1 vs QR2 (old QR1 does not fit current wheels), shaft play, brake reads smoothly to 100% |
| Avoid | Belt bases priced near new direct drive, sellers who cannot show it working |
| Warranty | Usually does not transfer (Fanatec, Thrustmaster) |
