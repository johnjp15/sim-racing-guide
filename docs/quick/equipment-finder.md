## Decision flow
```
START -> What discipline? (track/rally/drift/truck/sandbox - decides rim/shifter/seat)
      -> Platform? PS5=Xbox=licensed SKUs only; PC=any ecosystem
      -> Space? fold=Tier0-1 (<=5.5-8 Nm); fixed=Tier2+
      -> Seating? Formula vs GT vs upright (GT = all-rounder)
      -> Budget? <$700 T0/1 | $1.2-1.6k T2 | $1.8-2.5k T3 | $3.5k+ T4 | $10k+ T5
      -> Games? iRacing/triples/VR/mods = PC required
```

## By discipline
See full matrix: [Disciplines](../disciplines/index.md)
| Want to drive | Rim / controls priority | Start tier |
|---|---|---|
| Competitive track (iRacing/ACC/LMU) | GT/formula rim, load-cell 2-pedal, paddles | Tier 2+ |
| Rally | Round 300mm+, sequential/H, handbrake, 3 pedals often | Tier 2+ fixed rig for handbrake forces |
| Drifting | Round rim, handbrake essential, H/sequential | Tier 2+ |
| Trucking | Large round rim, H-pattern + button box, relaxed upright | Tier 1+ |
| BeamNG / sandbox | Round rim, H + handbrake, durability over torque | Tier 1-2 |
| Road practice / cruising | Round rim, H or paddles, triples/VR immersion | Tier 1+ |
