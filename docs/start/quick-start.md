## 2. Set it up

| Step | Do this |
|---|---|
| Wheel | Clamp it to the front edge of your desk |
| Pedals | On the floor, against the wall |
| Chair | Block it. Caster cups, or rear wheels in old shoes |
| Screen | As close as it goes, right behind the wheelbase |
| Software | Install the maker's app. Update firmware first |

- About 30 minutes

## 3. Three settings

| Setting | Do this |
|---|---|
| Field of view | Measure screen width and eye distance. Put both in an FOV calculator. Enter the result in the game |
| Wheel rotation | Maximum in the wheel software. Let the game match each car |
| Force feedback | Lower the in-game gain until the heaviest corner stops maxing the meter |

- Detail: [First Setup](first-setup.md)

| You have | Start with |

## 5. First drive

- A slow rear-wheel-drive car on a short track. A Mazda MX-5
- Slower than a controller for a week or two. Normal
- Aim for 10 clean laps in a row, not one fast one
- 30 to 60 minutes a session
